## Sobre mim

Engenheiro de Software com formação em Análise e Desenvolvimento de Sistemas pela FATEC. Atualmente atuo no desenvolvimento de aplicações back-end com Java e ecossistema Spring, com foco em arquiteturas escaláveis, microsserviços e integração contínua.

Minha trajetória inclui a participação na primeira Piscina da 42 São Paulo, experiência que me expôs a desafios complexos de programação e metodologias colaborativas de alto desempenho. Busco constantemente aprimorar minhas habilidades técnicas e contribuir para soluções que gerem impacto real.
